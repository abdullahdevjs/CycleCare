# CycleCare V20 — Company Polish

V20 continues the V18 blueprint and V19 account-center baseline.

## UI
- Unified History & Insights with the blue/white blueprint system.
- Standardized analytics cards, tabs, wellness rows and edit modals.
- Added stronger keyboard focus states to Account Center controls.
- Preserved responsive and reduced-motion behavior.

## Data / functionality
- No database schema changes in V20.
- Existing Supabase authentication, cycle history, wellness history, reminders and PDF export remain unchanged.
- Existing `.env` credentials remain user-managed and are not bundled.
