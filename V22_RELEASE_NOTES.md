# CycleCare V22

- First-time users are routed to Cycle Setup before Dashboard.
- First-time Cycle Setup date, cycle length and period length fields are blank; saved values are shown only for existing profiles.
- Dashboard no longer invents 28/5 defaults when cycle profile data is incomplete.
- Log Period refuses to create a history record until a valid cycle length exists.
- Existing blue blueprint UI and Supabase schema are preserved.
